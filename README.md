# claude-log-viewer

Claude Code の会話ログ（`~/.claude/projects` の JSONL）を、ブラウザでまとめて検索・閲覧するためのローカルサーバーです。どの Issue・PR・リポジトリ・ファイルを扱ったセッションかで絞り込めるので、長いセッションや「あれはどのセッションだったか」を探しやすくなります。

依存パッケージはありません。

## 起動

Node.js 20 以上が必要です（動作確認は Node.js 24）。

```sh
git clone https://github.com/Marco3jp/claude-log-viewer.git
cd claude-log-viewer
npm start
```

http://127.0.0.1:4317/ を開きます。

| 環境変数 | 既定値 | 内容 |
|---|---|---|
| `PORT` | `4317` | 待ち受けるポート |
| `CLAUDE_PROJECTS_DIR` | `~/.claude/projects` | 会話ログを読むディレクトリ |
| `CLAUDE_LOG_VIEWER_DATA` | `~/.local/share/claude-log-viewer` | ブックマークの保存先（`XDG_DATA_HOME` があればその下） |

## できること

### セッションを探す

- 左の検索欄で全文検索します。スペース区切りで AND、`"…"` でフレーズ、先頭に `-` で除外です
- 検索の対象は、ユーザーの発言・Claude の返答・思考・ツールの入力と結果（先頭 4,000 字）・サブエージェントのやり取りです
- 「詳細検索」を開くと、次の条件で絞り込めます。候補には件数が出て、クリックすると条件に加わります
  - リポジトリ（作業ディレクトリの `.git/config` から GitHub の `owner/repo` を出します）
  - Issue・PR（GitHub の URL、`gh pr view 123` などのコマンド、Claude Code が記録した PR のリンクから拾います）
  - 読み書きしたファイル・ディレクトリ（パスの一部で指定し、読んだ・書いたを選べます）
  - 期間、プロジェクト、ブランチ、使ったツール、MCP サーバー、ブックマーク
- 条件は URL に入るので、ブラウザのブックマークでも同じ検索を開き直せます
- `/usage` のようなローカルコマンドだけで Claude の返答が無いセッションは、一覧に出しません。詳細検索の「返答の無いセッションも出す」で出せます

### セッションを読む

- ヘッダーに `claude --resume <id>` のコピーボタン、関わった Issue・PR、読み書きしたファイルの一覧が出ます
- 思考・Bash・ツール・MCP・サブエージェント・システムを、種類ごとに表示・非表示できます
- セッション内検索で、一致した箇所へ前後に移動できます。非表示にしている種類の中の一致は件数だけ出ます
- 右端の目次にプロンプトが並び、プロンプトごとの一致件数も出ます
- Claude の返答は Markdown として表示します。表は等幅フォントです
- サブエージェントの呼び出しを開くと、その中のやり取りをその場に展開できます
- ★ でセッションをブックマークできます
- 一覧・ヘッダー・目次は、境目のドラッグで大きさを変えられます。ボタンで畳めて、ダブルクリックで元の大きさに戻ります

### キー操作

| キー | 動き |
|---|---|
| `/` | 検索欄へ移る |
| `⌘F` / `Ctrl+F` | セッション内検索へ移る |
| `Enter` / `Shift+Enter` | セッション内検索で次・前の一致へ |
| `R` | 一覧と表示中のセッションを読み直す |
| `Esc` | 詳細検索を閉じる |

## 気をつけること

- 会話ログにはコマンドの出力や認証まわりの情報がそのまま入っています。サーバーは `127.0.0.1` でだけ待ち受け、`Host` ヘッダーが `127.0.0.1` か `localhost` のときだけ応えます
- ファイルの絞り込みに入るのは、Read・Edit・Write・Grep・Glob で扱ったファイルです。Bash の `cat` や `sed` で扱ったファイルは、全文検索で探してください
- 本文に `#123` とだけ書かれた Issue 番号は、どのリポジトリのものか決められないので拾いません
- ログの形式は Claude Code のバージョンで変わることがあります
- Windows では動作確認していません。パスを `/` 区切りで扱っている箇所があります
