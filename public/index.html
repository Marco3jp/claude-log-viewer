      操作使える場所キー操作名

      割り当てを変える

      操作名にキーの配列を書くと既定を置き換え、操作名の先頭に + を付けると既定に足します。空の配列 [] でその操作のキーを無くせます。修飾キーは Ctrl・Alt・Shift・Cmd・Mod（Mac では Cmd、ほかでは Ctrl）です。設定はこのブラウザに保存します。

      送信してから Claude に渡すまで、ここで決めた秒数だけ待ちます。待っている間は会話の末尾に仮の吹き出しが出て、「取り消す」かキー操作（既定は Esc）で取り消せます。取り消した文面は入力欄に戻ります。0 にするとすぐ送ります。この設定はこのブラウザに保存します。

      返事を書き終えたセッションには、一覧でいつも青い点が付きます。オンにすると、表示中でないセッションに返事が来たときと、確認待ちになったときに OS にも通知します。通知を押すと、そのセッションのその返事を開きます。この設定はこのブラウザに保存します。

      入力欄の上に出す 1 行の作り方を選びます。コマンドには、Claude Code がステータスラインのコマンドに渡すのと同じ形の JSON が標準入力で渡り、標準出力の 1 行目を出します。この設定はサーバーのデータ用ディレクトリに保存します。
